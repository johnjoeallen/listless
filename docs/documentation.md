# Maintaining Listless documentation

The GitHub Pages site is product-first: `index.md`, `getting-started.md`,
`usage.md`, `syntax-highlighting.md`, `configuration.md`, and `roadmap.md`.
The original-source research and subsystem notes are in `porting/`; the
append-only engineering log is
[`PORTING_JOURNEY.md`](https://github.com/johnjoeallen/listless/blob/main/PORTING_JOURNEY.md).

Planned functionality must have a visible **not implemented** or
**upcoming feature** marker.
